Auto-Activate .venv on cd (one-time setup)

Install direnv so the virtual environment activates automatically every time you cd into the project:

brew install direnv
echo 'eval "$(direnv hook zsh)"' >> ~/.zshrc
source ~/.zshrc
cd /path/to/Finalproject
direnv allow .
After this, the .venv activates silently on every cd — no manual source .venv/bin/activate needed.
